# Rat-In-a-Maze
Rat in a Maze is an problem where an rat is placed at it's intial position(0,0) in an nxm grid.Then we need find that the rat can reach at the specified n-1 x m-1 position in which 0 represents free cell and 1 represents blocked cell and only down and right movement are allowed .And we have to find the path if it exists.
